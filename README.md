# WellnessCare

A React-based wellness education website built with Vite.

## Features

* Wellness home page and navigation
* General wellness assessment
* Mental health and physical activity information
* Sleep, social well-being, and health insights pages
* Research references and educational resources
* Responsive interface

## Tech Stack

* React
* Vite
* React Router
* Lucide React
* Recharts

## Run locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Deployment

The project can be deployed as a static site on Render.

* Build command: `npm install && npm run build`
* Publish directory: `dist`

If client-side routes show a 404 after refreshing, configure the hosting service to rewrite application routes to `index.html`.
